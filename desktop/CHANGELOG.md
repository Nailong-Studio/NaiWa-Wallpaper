# Changelog

## v0.0.3（2026-11-20）

从 Windows 单平台扩到 Windows + Linux 桌面。

- 新增 Linux 壁纸后端：GNOME / Cinnamon / MATE / KDE Plasma / XFCE / Sway / Hyprland。
- 没有已知桌面环境时，支持通用 X11 兜底（feh 或 xwallpaper）。
- 界面文案从 Windows 专用改为跨平台；对外名称统一为 NaiWa Wallpaper / 奶蛙壁纸。
- 版本升到 0.0.3。
- 保持 205 张精选素材、本地离线、无账号、无网络请求。

## v0.0.2（2026-11-20）

首个 Windows 桌面版原型。

- 205 张奶蛙壁纸，桌面横屏 / 手机竖屏 / 方形 / 4K / 姿势五类。
- 搜索、分类筛选、大图预览、收藏、随机一张、下一张。
- 一键设为 Windows 桌面壁纸；设置前统一转高质量 JPG，兼容 WebP 原件。
- 定时自动轮换（30 分钟 / 1 小时 / 1 天，程序运行期间生效）。
- 本地离线，无账号、无网络请求、无遥测。
